## 🔔 3D Controller Overlay + v1.4.2

A small release that makes first launch clearer and modernizes the Linux AppImage, so 3dco+ can be listed in the AppImage catalog.

### 👋 A proper first-launch screen

On a fresh install the Settings window used to be almost empty: just a small "New" tab on a blank background, with nothing saying what to do. It now shows a "No controllers created yet" panel that explains you need to create your first controller (which also unpacks the bundled models), with a **Create Controller** button that does the same as "New". Once a controller exists, the panel goes away and everything works as before.

### 🐧 AppImage no longer needs libfuse2

The AppImage is now built with the maintained `appimagetool` and its statically linked runtime, instead of the old, deprecated AppImageKit one. It no longer depends on `libfuse2` being installed, which newer distributions (Ubuntu 24.04 and later, among others) don't ship by default.
